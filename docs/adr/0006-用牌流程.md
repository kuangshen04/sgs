# ADR-0006 用牌流程：目标阶段 + 单目标生效事件

状态：已落地（阶段 3 第 8 项 U1–U5；无懈/仁王盾/青釭剑/离间/方天画戟均落在其上）
落地位置：`src/flow/useCard.ts`（`useCard` / `useVirtualCard`）、`src/rules/cardDef.ts`（CardDef 协议）

## 背景与问题

"不生效"有三种语义被挤在一处：**目标不合法**（选择期规则）、**持续型无效**（仁王盾"黑色【杀】对你无效"）、
**响应型抵消**（闪/无懈）。早期实现里后两者都用 `targeting.cancelled`（取消目标）顶替，导致
青釭剑（在目标指定后失效防具）与仁王盾撞车；"无懈抵消的是一张牌对某个目标的效果"也表达不出来。

## 决策

### 流程（一条 UC 的一生）

```
useCard({ player, card: UC, targets })
 ① UC 入处理区（实体牌跟随；ADR-0003 的 enter）
 ② 目标阶段：逐目标 [targeting.before → targeting.after]
      每目标可置：cancelled（取消目标）/ disresponsive（不可响应）
 ③ 生效阶段（有目标）：
      onAction(before) → 逐目标依次 cardEffect → onAction(after)
        cardEffect.before   ← 触发时点：仁王盾置 nullified；无懈在此响应并置 cancelled
        cardEffect 内容      ← CardDef.content：只结算当前目标
        cardEffect.after    ← 触发时点
      引擎在内容前只检查 nullified / cancelled：置位 ⇒ 跳过内容（= 无效 / 抵消）
 ③'（无目标）单独分支：不伪造 target、不产生 targeting 事件
 ④ 收尾：清理处理区（仍在处理区的 UC 退出，实体牌入弃牌堆）
```

### 关键取舍

1. **以 trigger 为主，不引入固定时点协议**：生效阶段只有 `cardEffect.before/after` 两个事件时点
   （与 `damage.*`、`targeting.*` 同一套词汇），引擎在内容前后只做"无效/抵消则跳过"这一件事。
2. **`CardDef.content` 单目标结算**（读 `data.to`）；**响应写死在对应牌的内容里**（杀的闪、决斗的杀
   自己编排询问），内容可自行读 `disresponsive` 等位——引擎不提供"自动响应"框架。
3. **`CardDef.onAction(before|after)`** 承担整张牌的开幕/收尾（五谷丰登亮牌一次，牌池放 `use.extra`；
   南蛮/万箭/桃园只喊一次口号）。
4. **每目标位**（`CardEffectEventData`）：`nullified` / `cancelled` / `disresponsive` /
   `unoffsetable` / `cardsResponded`。目标阶段置的位随生效事件继承（`AimResult`）。
5. **响应关系显式记录**：`ResponseRequest.respondTo` → `UseCardEventData.responseTo`（无懈 content 据此
   给"它所响应的那次生效"置 `cancelled`）+ `effect.cardsResponded`（记录了哪些牌响应）。
   取代"沿事件栈反查父事件"。**反无懈由递归自然形成**（无懈自身也是一次无目标使用）。
6. **`unoffsetable`（事件级）**：整条牌不可被无懈响应 ⇒ 不开窗（离间的决斗）。
7. **另有两个入口与约定**：
   - `useVirtualCard(game, {player, card, targets, unoffsetable?, shaUsed?})`：技能"视为使用一张牌"的
     **引擎级合法性校验**入口（使用者 `canUse` + 逐目标 `targetFilter`，非法目标剔除、无合法目标不使用）；
   - 延时锦囊 / 装备的"使用效果"= 引擎提供的位置效果（在该目标的 cardEffect 内执行），因此**天然受
     `nullified` 约束**（被无效则不落地）。
8. **打出**（响应窗口）不走本流程：`usedCardActions.playUsedCard` = UC 进处理区 → 立即收尾
   （打出的"结算内容"为空）；真实牌与转化牌共用；八卦阵的零牌虚拟闪由响应型效果的 `virtualCard` 声明产出。

### 落点一览（标包）

| 牌/技能 | 目标阶段 | 生效阶段 |
|---|---|---|
| 仁王盾 | —— | `cardEffect.before` 置 `nullified`（黑色杀） |
| 青釭剑 | `targeting.after` 失效目标防具 UC（期限 = 本张牌收尾，`onClear`） | —— |
| 流离 | `targeting.before`：取消原目标 + 追加新目标 | —— |
| 铁骑 | `targeting.after`：判定红 → 该目标 `disresponsive` | —— |
| 雌雄双股剑 | `targeting.after` | —— |
| 方天画戟 | —— | `useCard.before`：UC 实体牌 == 手牌时追加 0–2 个合法目标 |
| 八卦阵 | —— | 杀的内容询问闪时的响应候选（`virtualCard: 闪`） |
| 无懈可击 | —— | 无目标流程的 `cardEffect.before` 响应窗口；内容置响应对象的 `cancelled` |
| 离间 | —— | `useVirtualCard` 构造 0 牌决斗（`unoffsetable`） |
| 奸雄 / 遗计 / 刚烈 | —— | 伤害事件（不变） |

## 影响与后果

- 已声明的行为变化：① 无目标使用不再伪造 target（无懈窗口改挂它自己的 `cardEffect.before`）；
  ② 无懈窗口从"目标指定阶段"移到"逐目标生效前"（与该目标结算交错，顺序更贴规则）；
  ③ 仁王盾的无效判定移到生效阶段（青釭剑 vs 仁王盾 由**阶段**保证，不依赖排序）；
  ④ 不可响应改为每目标位（修掉多目标杀里铁骑的跨目标污染）；⑤ 打出的牌经处理区再进弃牌堆。
- 新增"一条牌对某目标无效/被抵消"的能力，是离间、方天画戟、青釭剑、仁王盾四件内容的共同基础。
