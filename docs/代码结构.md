# 代码结构

> 一页导览：`src/` 目录职责、依赖方向与常用入口。目录约定变更时同步更新本文件与 `AGENTS.md`。

## 目录一览

```
src/
  index.ts          入口（组装一局并跑主循环）
  game.ts           Game 容器 + createGame（初始化显式步骤）
  types.ts          共享类型（Card/Player/GameState/CardLocation/RespondMarks…）
  test-utils.ts     测试辅助（freshGame / giveHand / makeUniqueCard / equipAt / placeIn）

  events/           事件系统
    GameEvent.ts      事件对象与生命周期（id/endId/clear 钩子/事件栈）
    TriggerSystem.ts  发布订阅注册表（on/off/trigger）
    history.ts        历史范围查询（findEventSince）
    types.ts          事件名常量 + 各事件数据类型
    index.ts          统一导出

  position/         位置模型（牌在哪、怎么移动）
    cardArea.ts       受控容器 CardArea + 集中索引（一牌一位置）
    cardAreaCheck.ts  对账不变量（verifyCardState / assertCardState）
    areas.ts          规则语义"区域"（手牌/装备/判定）查询辅助
    cardActions.ts    移动原语（moveCards / 牌堆原语 / 语义封装 / useCard）

  effects/          效果与技能（规则行为的统一模型）
    effects.ts        Effect 五形态 + defineSkill/registerBareEffect + 技能实例
    skills.ts         装载与分发（installEffects）+ 主动效果查询
    persistentEffects.ts  常驻效果查询面（effectRegistry.sum/has）
    conversions.ts    转化效果查询面

  decision/         决策与窗口（玩家/ AI 输入层）
    selection.ts      选择会话原语（SelectionPlan/Step/Session）
    choose.ts         选择步骤工厂 + ask 家族 + 规则可选集计算
    useWindow.ts      通用用牌窗口（动作选择 + continuation）
    playChoices.ts    出牌阶段动作编排（牌/主动效果/转化）
    responses.ts      响应窗口（候选构建 + 执行）

  flow/             流程与结算
    gameFlow.ts       game/round/turn/phase 边界 + 出牌/弃牌流程
    life.ts           伤害/回复/失去体力/濒死/死亡（GameOverError）
    respond.ts        响应流程（杀→闪、决斗、南蛮、万箭、桃、无懈入口）
    distance.ts       座位距离与攻击范围
    display.ts        控制台展示

  content/          内容定义与注册（引擎的"数据/内容"面）
    cardRegistry.ts   卡牌定义注册表（CardDef）
    heroRegistry.ts   武将定义注册表（HeroDef）
    deck.ts + standardDeck.json  标准牌堆数据映射（108 张）
    cards/            基本牌 / 锦囊 / 装备 / 延时锦囊定义与效果注册
    heroes/           25 位标包武将（技能效果注册 + 各武将测试）
```

## 依赖方向

- `content/` → 引擎各簇（内容只注册，不反向被引擎依赖；唯一例外是 `game.ts` 以副作用 import 触发注册与初始装载）。
- `events/` 是最底层，不依赖其它簇；`position/` 依赖 `events/` 与 `types`。
- `effects/` 依赖 `events/`、`position/`（效果行为里会移动牌）；`decision/`、`flow/` 在两者之上。
- 入口 `index.ts` 只做组装；`game.ts` 负责一局的生命周期起点。

## 常用入口

| 想做什么 | 看哪里 |
|---|---|
| 建一局 / 初始化步骤 | `game.ts` → `createGame`（步骤见注释；阶段 4 身份场、阶段 5 rng 接入点已标） |
| 注册技能/效果 | `effects/effects.ts` → `defineSkill` / `registerBareEffect`（技能 = 元数据 + 效果集合） |
| 本局装载效果 | 已内置在 `createGame`（`effects/skills.ts` 的 `installEffects`，幂等） |
| 移动牌 | `position/cardActions.ts` → `moveCards`（唯一跨容器通道；顶/底用 putTop/putBottom） |
| 查牌的位置 | `position/cardActions.ts` → `getCardArea`（集中索引） |
| 玩家决策 | `decision/` 各模块（ask 家族/选择计划/用牌窗口/响应窗口） |
| 事件历史查询 | `events/history.ts` → `findEventSince` |
| 对账/调试不变量 | `position/cardAreaCheck.ts` → `verifyCardState` / `assertCardState` |

## 测试

测试与被测模块同目录（`src/<cluster>/xxx.test.ts`；`content/heroes/*.test.ts` 随武将）。全量：`pnpm exec vitest run`；类型：`pnpm exec tsc --noEmit`。
